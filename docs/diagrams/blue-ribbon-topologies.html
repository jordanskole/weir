The program, as weir sees it

Four topologies, drawn from the declarations. Rectangles are nodes, ellipses are edges — which is not a stylistic choice: weir's execution model is a Petri net, where edges are the places that hold tokens and nodes are the transitions that fire. The picture alternates between them because the program does.

The entry point. Three of its seven boxes are other topologies referenced where a node would go — each inlined at elaboration, each running in a different zone, drawn dashed. routeCounty is the only branch; resolveIdentity is the only fan-in, and it waits for two edges that are nine steps apart in lineage.

the three referenced topologies · one effect node each

Each is one node wide. That is the whole point of them: a topology is the unit of placement, so a single node that runs somewhere else needs its own topology to say so. All three have identical shape and three different counterparties — and two of them talk to a county's own server while the third talks to a commercial aggregator standing in front of one.
